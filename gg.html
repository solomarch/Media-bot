Basic Tags

1.Structure Tags


Used to organize content in a document.


  • <area> - Defines a clickable area inside an imae map.
  • <article> - Represents indepndent self-contained content.
  • <aside> - Content indirectly related to te main content(like sidebars).
  • <base> - Sets te base URL for all relatiive links ina document.
  • <canvas> - Used to draw graphics usin JavaScript.
  • <div> - Generic container for content, used for layout/styling.
  • <section> - Represents a tematic grouping of content.
  • <header> - Define a page or section header.
  • <footer> - Define a page or section footer.
  • <main> - Highlights the dominant content of a page.
  • <nav> - Contains navingation links.
  • <summary> - Used with <details> to define a visible heading.
  • <h1> to <h6> - Heading Tags.
  • <p> - Paragraph Tag.
  • <pre> - Preformatted Text.
  • <hr> - Horizontal Rule.
  • <br> - Line Break.

2.Text Formatting Tags


Used to change the appearance or emphasis of text.


  • <b> - Bold text(Visual only).
  • <strong> - Important text(semantic).
  • <i> - Italic text(visual).
  • <em> - Emphasis text(semantic).
  • <u> - Underline text.
  • <small> - Smaller Text.
  • <mark> - Highlighted or marked Text.
  • <del> - Deleted/struck-through Text.
  • <ins> - Inserted Text.

3.Sub/Superscript & Abbreviation


  • <sub> - Subscript text(e.g., chemical formulas).
  • <sup> - Superscript text(e.g., exponents).
  • <abbr> - defines an abbreviation, shows full form on hover.

4.Code & Technical Tags


Used in coading or to show technical content.


  • <code> - Represents code snippets.
  • <kbd> - Denotes user input vai keyboard.
  • <samp> - Represents sample output from a program.
  • <var> - Defines a variable in a programming or mathematical expression.

5.Time & Quotation


  • <time> - Represents a specific date/time.
  • <q> - Defines short inline quotation.
  • <cite> - Indicates a citation or reference(e.g., books, article).

6.Generic Inline Container


  • <span> - Generic inline container(for styling with CSS)

7. Multimedia Tags


  • <audio> - Embeds sound/audio content.
  • <object> - Embeds multimedia like PDF or Flash(rarely used now).
  • <source> - Specifies media resources for <audio> or <video>.

8. Style & Scripting


  • <style> - Adds CSS styling inside HTML.
  • <script> - Adds JavaScript logic to a page (crossed out in your notes but valid).
